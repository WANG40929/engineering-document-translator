快速开始

  1. 双击 DocumentTranslator.exe。第一次启动后打开右上角“设置”。
  2. 选择 API 供应商，填写自己的 API Key，确认接口地址和模型，然后保存。API Key 不包含在软件包中。
  3. 将 PDF、Word、Excel 或 CSV 文件拖入窗口，也可以点击选择文件。
  4. 确认源语言、目标语言和输出目录，点击“开始翻译”。
  5. 任务完成后点击“打开”查看译文，或点击“打开文件夹”定位输出文件。
紧急插队：翻译过程中点击紧急文件右侧的“向上箭头”。软件会在当前接口请求结束后的安全检查点暂停当前文件， 先完成紧急文件，再利用缓存继续原文件；为保护成品，正在保存文件时不会被强制中断。
推荐：PDF 模式保持“自动选择”。软件会根据页面内容选择智能排版或原位保版； Word、Excel、CSV 不使用 BabelDOC 引擎。

API 供应商与备用服务

内置 DeepSeek、OpenAI、Anthropic Claude、Google Gemini、阿里云百炼/Qwen、Azure OpenAI、Moonshot/Kimi、智谱 GLM、火山方舟/豆包、SiliconFlow、OpenRouter、Mistral、Groq、Together AI，以及本地 Ollama、LM Studio、vLLM。还可填写任意 OpenAI-compatible 接口。

每个服务配置独立保存接口、模型和 Windows 加密的 API Key。可以设置故障备用服务。缓存会按供应商、协议、接口和模型隔离。软件显示服务端实际返回的 token，不估算费用。

PDF 模式和输出

自动选择（推荐）

正文较多的报告、手册和论文优先使用智能排版；图纸、铭牌和短标签 PDF 优先使用原位保版。完整版找不到智能引擎时会显示明确提示。

智能排版

使用 BabelDOC 分析段落、字体和页面结构，再将所选模型服务的译文放回页面。适合连续正文。v1.5.0 支持多个 API 服务配置；BabelDOC 需要 OpenAI-compatible 接口，原生 Anthropic 可配置兼容备用服务或使用原位保版。生成后会逐页检查裁切、遮字、残留源文、文字行重叠、结构异常和小字号。

原位保版

尽量在原文字坐标处替换内容。适合工程图纸、表格、铭牌和版面位置不能变化的文件。

PDF 可以生成纯译文、双语对照，或同时生成两者。图片内部的文字默认不会 OCR 翻译。

进度、速度和缓存

  • PDF 任务会依次显示版面分析、术语处理、正文翻译、重新排版、排版自检、问题页修复和输出等阶段。
  • 预计剩余时间根据近期处理速度计算，网络波动时可能调整。
  • 相同文本和已成功结果会尽量复用，在不降低模型、术语和排版质量的前提下减少等待。
  • 主翻译缓存超过 100 MB 后按时间自动清理；智能引擎的模型和字体不属于这 100 MB 缓存。
  • v1.4.0 为防止复用旧版潜在串段结果，首次翻译不会复用 v1.3.x 的旧缓存；旧记录仍会按 100 MB 上限自动清理。
  • 可选择 CSV、TSV、TXT 或 XLSX 术语表，软件会记住并继续使用。v1.4.0 尚不会自动建立永久术语库；译文缓存也不等于术语库。

轻量版自行安装 BabelDOC

只有需要“智能排版”PDF 时才需要执行本节。安装过程需要联网，首次下载模型和字体会占用较多磁盘空间。
  1. 安装 64 位 Python 3.12。
  2. 打开 PowerShell，逐行运行：
py -3.12 -m venv "$env:LOCALAPPDATA\DocumentTranslator\babeldoc-env"
& "$env:LOCALAPPDATA\DocumentTranslator\babeldoc-env\Scripts\python.exe" -m pip install --upgrade pip
& "$env:LOCALAPPDATA\DocumentTranslator\babeldoc-env\Scripts\python.exe" -m pip install BabelDOC==0.6.4
& "$env:LOCALAPPDATA\DocumentTranslator\babeldoc-env\Scripts\babeldoc.exe" --warmup
  1. 在软件“设置 → 高级”中选择下面的引擎文件：
%LOCALAPPDATA%\DocumentTranslator\babeldoc-env\Scripts\babeldoc.exe

如果电脑没有 py -3.12 命令，可将第一行开头改为 python。

常见问题

双击后没有立即出现窗口

安装版和 v1.4.0 文件夹式免安装版已减少启动解压。首次运行仍可能被 Windows Defender 扫描，请等待片刻；不要反复双击。

提示没有智能 PDF 引擎

完整版请确认 TranslationEngine 与主程序在同一目录。轻量版请按上一节安装，并在设置中选择 babeldoc.exe。

进度一段时间没有变化

查看任务阶段文字。版面模型首次载入、模型服务网络响应或大页重新排版可能需要时间；只有软件明确报告停滞或失败时才需要重试。

翻译文件在哪里？

输出目录显示在主界面顶部。完成后可直接点击任务右侧的“打开”或“打开文件夹”。

API Key 会随安装包公开吗？

不会。公开安装包不包含任何 API Key、用户配置、翻译缓存、报告或源文档。请不要把自己的配置目录上传给他人。

English quick guide

Version: {{VERSION}} · Edition: {{EDITION}}

  1. Run DocumentTranslator.exe.
  2. Open Settings, choose an API provider, enter your own key, verify the endpoint and model, and save.
  3. Drag PDF, Word, Excel, or CSV files into the window.
  4. Choose source language, target language, and output folder, then select Start Translation.
  5. When complete, use Open File or Open Folder beside the task.

Urgent priority: select the upward arrow beside an urgent file. The application pauses the active file at a safe checkpoint, finishes the urgent file first, then resumes the original file from cache.

API providers and fallback

Built-in profiles cover DeepSeek, OpenAI, Anthropic Claude, Google Gemini, Alibaba Model Studio/Qwen, Azure OpenAI, Moonshot/Kimi, Zhipu GLM, Volcengine Ark/Doubao, SiliconFlow, OpenRouter, Mistral, Groq, Together AI, and local Ollama, LM Studio, and vLLM. Any OpenAI-compatible endpoint can also be entered manually.

Each profile has a separate endpoint, model, and Windows-encrypted key. An optional failure fallback can be selected. Cache namespaces are isolated by provider, protocol, endpoint, and model. Actual returned tokens are recorded; prices are not estimated.

Editions

  • Setup Full: recommended; installs the application and bundled BabelDOC smart-PDF engine.
  • Portable Full: same translation capability without installation. Extract the entire archive first.
  • Portable Lite: smaller and does not include BabelDOC. Strict-layout PDF, Word, Excel, and CSV remain available.

Do not separate runtime folders

ApplicationFiles is required by the application. The Full edition also requires TranslationEngine. Keep both beside the EXE.

PDF modes

Automatic is recommended. Smart Layout is best for reports and manuals; Strict Layout is best for engineering drawings, labels, and fixed-position content. In v1.4.4, every Smart Layout page is checked for half-clipped glyphs, rule-obscured text, isolated source fragments, overlapping lines, collapsed structures, abnormal distribution, and unreadably small text. Notice regions use their full available area, real tables remain cell-bounded, and every repair is rescanned and rolled back if it is less readable than the Smart Layout page. Image-only text is not OCR-translated by default.

Glossaries and cache

The selected CSV, TSV, TXT, or XLSX glossary is remembered and reused. v1.4.0 does not automatically build a permanent terminology library. Translation cache is capped at 100 MB and is not a terminology database. Version 1.4.0 does not reuse v1.3.x cache mappings, preventing potentially misaligned older results from entering repaired PDFs.

Install BabelDOC for the Lite edition

Install 64-bit Python 3.12, run the four PowerShell commands in the Chinese section above, then select the resulting babeldoc.exe under Settings → Advanced.

Privacy

Release packages contain no API key, user configuration, translation cache, report, or source document. Usage and charges are governed by the provider account configured by the user; the application does not estimate prices.
